# LinkedIn Ads

No official LinkedIn Ads MCP as of Nov 2026. All options need a LinkedIn Developer app with **Advertising API** access (LinkedIn reviews each request). Scopes: `r_ads`, `rw_ads`, `r_ads_reporting`.

| Repo / package | Notes |
|---|---|
| `mcp-linkedin-ads` (npm, mharnett) | 7 tools, write mode gated behind `LINKEDIN_ADS_MCP_WRITE=true` |
| `get-mcp-ads/linkedin-ads-mcp-server` | Node, token + account IDs via env |
| `cdatasoftware/linkedin-ads-mcp-server-by-cdata` | Read-only, Java + CData licence |
| `linkedin-mcp` in `cesteral/mcp-open-advertising` | Multi-platform suite |
