# Shopify

## Official — Shopify Dev MCP
- Shopify developer docs + API (GraphQL) schemas for building themes/apps. Runs locally, no sign-in.
- Useful for writing custom pixels / Web Pixels extensions and checkout tracking.
- Claude Code: `claude mcp add shopify-dev -- npx -y @shopify/dev-mcp@latest`

Shopify also runs a Storefront Catalog MCP — that's for shopping agents, not store management.
